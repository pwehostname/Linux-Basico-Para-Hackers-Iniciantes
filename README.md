# 😎 Tudo o que você precisa saber sobre Linux

Bem-vindo ao guia básico para começar sua jornada no mundo do **Linux** e da **segurança digital**. Este espaço foi criado para iniciantes, com foco no que você realmente precisa saber para gerenciar seu sistema e começar a se aprofundar na área de **segurança cibernética**.

## 🤔 Qual distribuição Linux escolher?

Para iniciantes e para quem quer focar em **segurança digital**, vamos começar com distribuições baseadas no **Debian**, como o **Parrot OS** . Essas distribuições são populares no mundo da segurança cibernética e oferecem várias ferramentas úteis para esse nicho.

- **Parrot OS Home**: Ideal para quem busca uma distribuição voltada para privacidade, segurança e desenvolvimento.
- **Parrot OS Security**: Mais conhecida entre os profissionais de segurança e hackers éticos, oferece uma vasta gama de ferramentas para testes de penetração.

## 🤨 O que vou aprender?

Aqui você aprenderá o suficiente para se tornar independente na administração do seu sistema Linux e também adquirir habilidades essenciais para a segurança digital. Entre os tópicos que abordaremos, estão:

### 🔧 Gerenciamento de Sistema
- **Instalar e remover programas**: Aprenda a instalar softwares e pacotes no Linux, utilizando o terminal de forma eficaz.
- **Atualizar seu sistema de forma segura**: Entenda como manter o seu sistema atualizado, sem comprometer sua segurança.
- **Personalizar seu sistema**: Dicas para deixar seu ambiente de trabalho no Linux do seu jeito.
- **Identificar e solucionar problemas**: Como lidar com erros comuns e resolver problemas que podem surgir no seu sistema.
